CloudflareBOX Windows 11 クイックスタート

1. このZIPを任意のフォルダへ展開します。
2. Install-CloudflareBOX.cmd を実行します。
3. Windowsのユーザーアカウント制御が表示されたら「はい」を選びます。
4. インストール後、タスクトレイの CloudflareBOX を開きます。
5. 「Cloudflareと連携」を押し、ブラウザで自分のCloudflareアカウントへログインします。
6. R2・D1・Worker・workers.dev は CloudflareBOX が自動で作成・修復します。
7. 「Androidを追加」からAndroid端末をペアリングします。Android端末は複数台追加できます。

利用者が入力する必要がないもの
- R2 Access Key / Secret
- R2バケット名
- D1データベースID
- Worker名
- API URL

「Cloudflare OAuth Client ID が配布物に設定されていません」と表示された場合、その配布版には公開OAuth Client IDが同梱されていません。配布者側の設定が必要です。

アンインストールは uninstall.ps1 を管理者として実行します。通常は受信履歴・復旧情報などのデータを残します。データも削除する場合だけ -RemoveData を指定します。
