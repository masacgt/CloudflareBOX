CFBox Windows 11 クイックスタート

1. このZIPを任意のフォルダへ展開します。
2. Install-CFBox.cmd を実行します。
3. Windowsのユーザーアカウント制御が表示されたら「はい」を選びます。
4. インストール後、タスクトレイの CFBox を開きます。
5. 「Cloudflareと連携」を押し、ブラウザで自分のCloudflareアカウントへログインして必要な権限を許可します。
6. 利用可能なCloudflareアカウントが複数ある場合だけ、Windowsに選択画面が表示されます。CFBox用のR2・D1・Workerを作成する1アカウントを選びます。
7. R2・D1・Worker・workers.dev・cron は CFBox が自動で作成・修復します。
8. 「Androidを追加」からAndroid端末をペアリングします。Android端末は複数台追加できます。

利用者が入力する必要がないもの
- R2 Access Key / Secret
- R2バケット名
- D1データベースID
- Worker名
- API URL

「Cloudflare OAuth Client ID が配布物に設定されていません」と表示された場合、その配布版には公開OAuth Client IDが同梱されていません。配布者側の設定が必要です。

アカウント選択画面をキャンセルした場合、CFBoxは選択待ちで停止します。もう一度「Cloudflareと連携」を押して選択をやり直せます。

アンインストールは uninstall.ps1 を管理者として実行します。通常は受信履歴・復旧情報などのデータを残します。データも削除する場合だけ -RemoveData を指定します。
